# Economics Analytics System

The **Economics Analytics System** is a Python-based data analytics project designed to analyse economic indicators across four key areas: **microeconomics, macroeconomics, international economics, and economic development**.

The project uses **Python, Pandas, NumPy, and OpenPyXL** to generate, clean, analyse, and consolidate economic data into a structured Excel analytics workbook.

### Key Features

* **Microeconomics analysis** – price, units sold, and demand indicators.
* **Macroeconomic analysis** – GDP, inflation, unemployment, and interest rates.
* **International economics** – exports, imports, exchange rates, and trade balance.
* **Development economics** – income per capita, Gini index, poverty rate, and life expectancy.
* **Data cleaning** – duplicate removal, missing-value handling, and standardised column names.
* **Unified economic model** – combines multiple economic datasets using common dates.
* **KPI calculations**, including:

  * Price elasticity of demand
  * GDP growth
  * Trade balance
  * Inclusive growth index
* **Excel reporting** – automatically generates a structured workbook with separate analytical datasets and a KPI dashboard.
* **Data visualisation** – includes economic trend charts for analytical review.

### Technology Stack

**Python | Pandas | NumPy | OpenPyXL | Excel | Git | GitHub**

### Project Objective

The objective is to demonstrate how economic data can be transformed into a **structured analytical model and management reporting tool**. The project combines data processing, economic analysis, KPI development, Excel automation, and version control into one end-to-end workflow.

The project is designed as a practical example of **financial and economic data analytics**, with potential applications in financial analysis, treasury, investment analysis, economic research, and management reporting.
